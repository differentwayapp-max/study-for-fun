# מאגר התלבטויות – קטלוג התרגולים

שאלות שבהן הניסוח או התשובה ניתנים לוויכוח, ולא טעויות ודאיות. לכל שאלה צריך להחליט עם מורה של השכבה: להשאיר, לנסח מחדש או להחליף.

- **סבב**: 1 = בדיקה ראשונה (17.11.2026), 2 = בדיקה אחרי התיקונים והשאלות החדשות (גרסה sff-v119).
- **מזהה**: מספר השאלה בגרסה הנוכחית (sff-v119), לפי הסדר בסט. מזהי סבב 1 עודכנו לגרסה הזו לפי טקסט השאלה. "(נוסחה מחדש/הוסרה)" פירושו שהשאלה שונתה בתיקונים, ואז המספר הוא מהגרסה הקודמת.
- **בקובצי המקור** `tools/sets/<id>.py` מחפשים את השאלה לפי הטקסט שלה.
- **הממצאים המלאים**: `reviews/` (סבב 1) ו-`reviews-round2/` (סבב 2).
