### פרומט 1: ערבוב קבוע לכל שאלה (לפני העלאה)
```
ריפו study-for-fun. קודם: git fetch origin claude/friendly-goldberg-0w7hhg && git checkout claude/friendly-goldberg-0w7hhg && git pull

ב-tools/build_set.py האפשרויות של כל שאלה (וגם שורות OPTS) מעורבבות ברצף אקראי אחד לכל הקובץ, לפי הסדר. לכן כל שאלה שנוספת מזיזה את האפשרויות של כל השאלות שאחריה. הלילה זה קרה ב-11 סטים, כשנוספו שאלות רמת מבחן.

תקן כך שהערבוב של כל שאלה ייקבע מהשאלה עצמה: seed ממזהה הסט + hash של טקסט השאלה והתשובה, ולא מהמיקום בקובץ. אז הוספה או הסרה של שאלות אחרות לא תזיז אף פעם שאלה קיימת.
- לשמור על פיזור התשובה (כ-25% לכל מקום, לבדוק עם SFF_PICSTATS=1).
- שורות ROW ושאלות סדר לא זזות, כמו היום.
- לבנות מחדש את כל סטי הקטלוג, אחד אחרי השני.
- עם האפליקציה מוגשת (python3 tools/serve.py 8765 &): IDS=<id> node tools/tests/local_scenes.js לכל סט, node tools/tests/local_optsq.js, וכל tools/tests/local_*.js.
- לעדכן את CLAUDE.md.
- commit ו-push לענף.
- לא להריץ deploy.
```
