- **מה הבדיקה מצאה:** כל 1,476 השאלות נבדקו. אין מפתח שגוי ואין טעות עובדתית או לשונית בתשובה המסומנת. הבעיות:
  - התנגשויות במשחקי ההתאמה.
  - שתי אפשרויות נכונות.
  - תמונות שמסגירות את התשובה.
  - הרבה כפילויות מול כיתות נמוכות יותר.
- **רמה:** כל ארבעת הסטים מתחת לרמה של מבחן אמיתי בכיתה ח'. **העמקת הרמה היא שלב ב'**, והיא ממתינה להחלטת הבעלים (ראו בסוף). **הסבב הזה מתקן רק את הממצאים.**
- **נקודת ההתחלה:** עובדים מ-main העדכני. מביאים את הדוחות ואת התיקון של `tools/match_list.js`:
  ```
  git fetch origin claude/friendly-goldberg-0w7hhg && git checkout origin/claude/friendly-goldberg-0w7hhg -- docs/catalog-review docs/grade-levels tools/match_list.js .claude/skills/build-practice-set/SKILL.md
  ```
- **הממצאים המלאים:** `docs/catalog-review/reviews-round8/{math8,heb8,en8,sci8}.md`.
  - המזהים (`sci8#81`) הם מספר השאלה בקובץ הבנוי של sff-v159. מאתרים לפי טקסט השאלה.
  - כל תיקון מוצע בדוחות נבדק מול הכללים, אבל בודקים אותו שוב.
- **חובה:** לפני שמתחילים, להפעיל את הסקיל `build-practice-set`. בסוף, להפעיל את `review-practice-set` על השאלות ששונו.

## איך עובדים
- מקור האמת: `tools/sets/<file>.py`. המגבלות של `build_set.py` נשארות.
- **בכל שאלה שמשנים בודקים:**
  - (א) התשובה נכונה.
  - (ב) אף מסיח לא נכון גם הוא.
  - (ג) המסיחים באותה צורה כמו התשובה.
  - (ד) התמונה לא מסגירה את התשובה.
  - (ה) אף קלף אחר באותו פרק לא עונה גם עליה (`node tools/match_list.js <id>`, תוקן ועובד).
  - (ו) אין שאלה זהה בשום סט של אותו מקצוע.
- **כשמשנים שאלה שמופיעה ב-`tools/core_facts.json`:** לעדכן גם שם.
- אחרי כל סט:
  - `SFF_DRY=1 SFF_PICSTATS=1 python3 -I tools/build_set.py tools/sets/<file>.py` ואז build.
  - עם האפליקציה מוגשת: `IDS=<id> node tools/tests/local_scenes.js` (0 bad scenes), וגם `node tools/tests/local_optsq.js`.
- לא לגעת ב-`docs/catalog-review/dilemmas.md`.
- **בסוף:**
  - commit ו-push.
  - **לא להריץ `tools/deploy.sh` לפני אישור.**
  - סיכום: מה תוקן, מה דולג, תוצאות הבדיקות.

## 2. כפילויות מול כיתות אחרות (ודאי)
מחליפים את השאלה בכיתה הגבוהה, ברמה גבוהה יותר. התחליפים המוצעים נמצאים בדוחות.
- **math8:**
  - «זוויות הבסיס בשווה שוקיים» = math5: לשאול את המשפט ההפוך.
  - «היקף מעוין 36» = math5: «AB=2x+1, BC=x+6 → x».
  - «3/5 = x/20» = math6: «x/(x+4) = 3/5».
  - 8 שאלות פיתגורס שחוזרות בתוך הסט על אותן שלשות: שלשות חדשות.
- **heb8:**
  - «לאילו בניינים אין שם פועל» = heb6. זו שאלה מ-core_facts, ולכן לעדכן גם שם.
  - «אחרי + אני» = heb6.
  - «אף שהיה קר, שחינו בים» = heb7.
  - «מוֹשָׁב → י־ש־ב» = heb6.
- **en8:** כפילויות מול en5, en6 ו-en7 (did you see the match, I promise I won't, much faster, mustn't/don't have to means, although means, isn't any sugar, visited the museum). את "means" מחליפים בשאלות ברמת משפט, ומעדכנים את core_facts.
- **sci8:** 12 כפילויות מול sci5, sci6 ו-sci7-materials, רובן בחשמל. מחליפים אותן בשאלות חישוב: מתח בטור, זרם ראשי במקביל, וולטמטר, משקל על הירח, מד-כוח.

## 3. תמונות ושאר הממצאים הקלים
לפי הסעיפים "תמונות", "התנגשויות" ו"קל" בכל דוח. במיוחד:
- **math8:** גרף שמתחיל ב-0 (שאלה על יחס ישר). ההסבר לשאלה על צ.צ.ז מתעלם מהמשפט הרביעי. מסיחים שאינם באותה צורה. 3 שאלות באותו פרק שהתשובה של כולן (2,3). רווח ב-«21₪».
- **en8:**
  - must/should בקלפים.
  - בתמונות: 💰 ליד "money", ו-👧 ל-"sister".
  - שגיאות אנגלית באפשרויות: «use alarm clock», «Dad lost glasses».
  - בפרק החזרה אין Passive ואין used to.
- **heb8:** 🔚, 🍼, והמשפט שחוזר בין שתי שאלות (פסיקים).
- **sci8:** 4 התנגשויות חלשות ו-2 תמונות.
