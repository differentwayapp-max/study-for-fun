## 1. העזר `Q` – פרמטר `lvl`
- בשני הקבצים: `Q(topic, q, opts, ans, expl, sc, lvl=1)`. השדה השביעי `2` נוסף רק כש-`lvl == 2`. נוסף גם `Q2(*a)` = `Q(..., lvl=2)`, כמו ב-math7 וב-sci8.
- **אימות לפני ההוספה:** הרצתי את הבנייה ב-`SFF_DRY` לפני השינוי ואחריו, ושמרתי את כל השאלות הבנויות. התוצאה זהה לגמרי, כולל סדר האפשרויות והתמונות: sci7 381 שאלות (hash `4beb609177` לפני ואחרי), materials 305 (`ad42af8d27`).
- **אחרי הוספת השאלות:** כל 381 + 305 השאלות הקיימות זהות בתוכן: טקסט, אפשרויות, תשובה, הסבר, פרק, core ותמונה, כולל מיקומי התמונות.
  - **סדר האפשרויות** השתנה ב-353 שאלות ב-sci7 וב-250 ב-materials. הסיבה: `build_set.py` מערבב את כל השאלות מאותו זרם אקראי, ולכן כל שאלה שמוכנסת באמצע הקובץ מזיזה את הערבוב של כל מה שאחריה. כך קרה גם בסבב 9 וב-math7. התשובה הנכונה לא משתנה, רק המקום שלה.

## 4. עובדות, יחידות וחישובים שנבדקו
- **חישובים:**
  - 24 + 16 = 40 (‏2Mg + O₂ → 2MgO); ‏150 − 146 = 4; ‏20 גרם / 0.5 ליטר = 40 גרם לליטר; ‏290 : 2 = 145; ‏200 − 120 − 30 = 50.
  - ‏60 + 25 = 85; ‏(20 + 50 + 50) : 3 = 40; ‏5 : 100 = 0.05 מ״מ (50 מיקרון, גודל תא סביר); ‏10 × 100 = 1000.
  - ‏18 × 4 = 72; ‏4 : 0.04 = 100 (טבלת האוויר הקיימת: 0.04% מול 4%).
  - ‏50·30·40 = 60,000 סמ״ק = 60 ליטר; ‏2 × 0.5 × 1 = 1 מ״ק; ‏50 : 10 = 5; ‏(55 − 40) : 5 = 3; ‏30 − 10 = 20.
  - ‏35 : 10 = 3.5 ק״ג; ‏0.2 × 10 = 2 ניוטון; ‏54 : 20 = 2.7 (אלומיניום); ‏50 : (50 − 30) = 2.5 (זכוכית); ‏40 : 0.5 = 80; ‏30 : 40 = 0.75 ← צף.
  - ‏3 × 4 = 12 גרם לליטר; ‏(80 − 20) : 10 = 6; באמצע בין 20 ל-60 = 40.
- **מסיסות סוכר:** בערך 200 / 240 / 290 גרם ל-100 מ״ל ב-20 / 40 / 60°C. הנתונים בכרטיס הם "לפי הטבלה".
- **מודלים:**
  - לחץ גז: יותר חלקיקים ← יותר פגיעות בדופן.
  - בקור החלקיקים מאטים ומתקרבים.
  - תעלה מסירה את חומר הבעירה; מפוח מוסיף חמצן.

  - במודל הריאות: מושכים את הגומייה ← הנפח גדל ← הבלונים מתנפחים.
- **ביולוגיה:**

  - עמילן נמצא רק בחלק המואר. בדיקת עמילן: מים רותחים ← כוהל (מוציא כלורופיל) ← יוד.
  - נשימה תאית: סוכר + חמצן ← CO₂ + מים + אנרגיה. מסלול הסוכר: דם ← תא ← מיטוכונדריה.
- **אנרגיה:**
  - סכר: גובה ← קינטית ← חשמלית. טורבינת רוח שטוענת סוללה: קינטית ← חשמלית ← כימית.
  - אנרגיית גובה ∝ גובה.
