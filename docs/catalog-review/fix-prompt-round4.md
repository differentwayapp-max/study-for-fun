## 1. קוד המשחקים (`public/index.html`), קודם כול
1. **`ansKey` הופך "D" ו-"d" לאותה תשובה.** זה באג חדש מהיום. ב-en3, "האות הגדולה של d?" שמחובר לכרטיס "d" מתקבל כנכון. הפתרון: להוריד לאותיות קטנות רק תשובות באורך של יותר מתו אחד.
   ```js
   const ansKey=q=>{const a=String(q.options[q.answer]).normalize('NFC').replace(/\s+/g,' ').trim(); return a.length>1?a.toLowerCase():a;};
   ```
2. **`needOpts` לא מזהה עברית מנוקדת.** למשל "אֵיזֶה מֵהֶם פְּרִי?" ב-heb1 וב-heb2 נכנסת למשחק ההתאמה בלי האפשרויות. הפתרון: להוריד ניקוד לפני הבדיקה: `t.replace(/[֑-ׇ]/g,'')`.
3. **להוסיף ל-`OPTS_HE` ניסוחים שחסרים:** `יוצאת דופן|אינו |אינה |אינם |אינן |איננה|כתוב נכון|כתובה נכון|כתובות נכון|מבין אלה|מאלה|איזה משפט נכון|באיזו מילה יש|יש טעות`. ולהוסיף ל-`OPTS_EN` את `\bcorrect\b`.
4. **הבדיקות:**
   - להוסיף ל-`tools/tests/local_optsq.js` בדיקות לשלושת התיקונים: שאלה מנוקדת, "יוצאת דופן", ו-"D" מול "d" במשחק ההתאמה, שצריך להיות "טעות".
   - להריץ את כל `tools/tests/local_*.js`.
   - להריץ ספירה: כמה שאלות יצאו ממשחק ההתאמה בעקבות התיקון. בכל סט צריכות להישאר מספיק שאלות לתחנת התאמה. אם לא, כתוב את זה בסיכום.

## 2. התנגשויות במשחקי ההתאמה (התלונה של ההורה)
