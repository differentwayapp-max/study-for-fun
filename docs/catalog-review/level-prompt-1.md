כתוב שאלות "רמת מבחן" (רמה ב') לסטים של הקטלוג. מתחילים ב-math7 (מספרים מכוונים ופילוג) ובשכבה ח'. ריפו: study-for-fun.

## הקשר
- **החלטת הבעלים:** "תרגול למבחן" (המפה הקיימת) מקבל שתי רמות בכל פרק:
  - **רמה א':** השאלות של היום, ברמת היכרות.
  - **רמה ב':** רמת מבחן. נפתחת כ-"⭐ שלב מבחן" אחרי שהתחנה עוברת, ונכנסת למבחן הדמה.
  - התוכנית המלאה: `docs/year-practice-plan.md`, חלון 2, סעיף ב.
- **בבדיקה נמצא:**
  - דף עבודה אמיתי של כיתה ז' דורש הרבה יותר ממה שיש ב-math7 (`docs/grade-levels/math7.md`).
  - בכל ארבעת הסטים של ח' רוב השאלות הן שליפה או צעד אחד. מה שחסר מפורט בסעיף "התאמה לרמת כיתה ח'" בכל דוח ב-`docs/catalog-review/reviews-round8/`.
- **נקודת ההתחלה:** עובדים על הענף `claude/friendly-goldberg-0w7hhg`, ולא על main. **מתחילים רק אחרי שסבב התיקונים של ח' (`fix-prompt-round8.md`) נדחף לענף**, כי הוא משנה את אותם קבצים.
  ```
  git fetch origin claude/friendly-goldberg-0w7hhg && git checkout claude/friendly-goldberg-0w7hhg && git pull
  ```
  - אם ה-push נדחה (סשן פיתוח דוחף לאותו ענף): `git pull --no-rebase`, ואז push שוב.
- **סימון רמה ב':** שדה שביעי בשאלה בקובץ הסט: `Q(...)` ואחריו `, 2`. כלומר `(topic, q, opts, ans, expl, sc, 2)`.
  - `build_set.py` כותב `"lvl": 2`.
  - **האפליקציה עוד לא מפרידה את הרמות** (שלב 3 בתוכנית, נבנה בנפרד). לכן **לא להעלות לאתר** עד שהשלב הזה נכנס.

## איך עובדים
- **חובה:** להפעיל את `build-practice-set` לפני הכתיבה, ואת `review-practice-set` בסוף. כל הכללים חלים:
  - 4 אפשרויות, עד 3 מילים כל אחת.
  - הסבר עד 10 מילים.
  - אין התנגשות בהתאמה.
  - אין כפילות בשום סט של המקצוע.
  - תמונות לפי הכללים.
  - **זכויות יוצרים:** לא מעתיקים מדף העבודה. כותבים תרגילים חדשים באותו סוג ובאותה רמה.
- **רמה ב' נכנסת בתוך הפרק הקיים,** בסוף רשימת השאלות שלו. לא מוסיפים פרקים חדשים ולא משנים את סדר הפרקים, כי ההתקדמות של ילדים נשמרת לפי מספר הפרק.
- **כ-10 שאלות לכל סוג משימה** (הכלל החדש בסקיל). המסיחים הם הטעויות הנפוצות: סימן הפוך, סדר פעולות שגוי, חילוק משמאל לימין שבוצע הפוך.
- **שאלה שצריך לראות בה את האפשרויות** (נכון / ייתכן, "איזה מספר מתאים"): לנסח כך שתיתפס ב-`needOpts`, כדי שתישאר בבחירה מרובה.
- **מגבלת המילים בשאלה (12):** אם שאלה רב-שלבית לא נכנסת, הנתונים עוברים לכרטיס בתמונה (`TXT` / `TAB` / `SC`). לא מעלים את המגבלה.
- **אחרי כל סט:**
  - `SFF_DRY=1 SFF_PICSTATS=1 python3 -I tools/build_set.py tools/sets/<file>.py`
  - build
  - `node tools/match_list.js <id>`
  - `IDS=<id> node tools/tests/local_scenes.js` (0 bad scenes)
  - `node tools/tests/local_optsq.js`
