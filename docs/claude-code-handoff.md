## מה האפליקציה
תרגול למבחנים דרך משחקים, לילדים מכיתה א' עד י"ב.
- **ההורה** מגדיר ילדים, ובונה לכל ילד תרגול לקראת מבחן: מקצוע, תאריך מבחן, נושאים, ודפי דוגמה (צילום / תמונות / קישור + עמודים / טקסט).
- **ה-AI (Claude)** סורק את החומר, בונה שאלות לפי פרקים, מוודא כיסוי של כל הנושאים, הופך כל שאלה לשאלת תמונה, ומריץ QA.
- **הילד** משחק ב-4 משחקים, צובר כוכבים וגביעים יומיים, ומתקדם במסלול פרקים עד המבחן.

## ארכיטקטורה
- קוד האפליקציה מדבר עם `window.claude.use('db' | 'sample' | 'user')` – אותו ממשק כמו ב-claude.ai artifacts.
  ב-`public/index.html` יש **גשר** (script type=module בראש הקובץ) שמממש את שלושתם עם Firebase:
  - `db` → Firestore, תחת `families/{familyId}/…`
  - `sample.json(prompt, {images, modelTier})` → Cloud Function `ask` → Claude
  - `user.isOwner()` → הורה מחובר
- **כניסה:** הורה = Google. מכשיר של ילד = כניסה אנונימית + קוד הזמנה מהלינק.
- **לינק לילד:** `https://<site>/?f=<familyId>&t=<inviteToken>#kid-<kidId>`. בפתיחה ראשונה המכשיר יוצר `families/{f}/devices/{uid}` עם הקוד, ומאז "נעול" על הילד (רק מסכי ילד).
- **מודלים** (`functions/index.js`): quick → `claude-haiku-5-5`, default → `claude-sonnet-5-5`, complex → `claude-opus-5-5`. המפתח: secret `ANTHROPIC_API_KEY`. רק הורה (לא אנונימי) יכול לקרוא ל-AI.

### Firestore
```
families/{parentUid}            { inviteToken, createdAt }
  /fam/kids                     { list: [{id, name, grade, color}] }           ← הורה כותב
  /sets/{setId}                 { set: {...תרגול מלא} }                        ← הורה כותב
  /progress/{kidId}             { history: [...], profile: {nick, avatar} }    ← הורה או מכשיר ילד
  /devices/{uid}                { token, at }                                  ← מכשיר מצטרף פעם אחת
```
גם localStorage שומר הכול על המכשיר (`sff_kids`, `sff_sets`, `sff_history`, `sff_lock`, `sff_fam`, `sff_tok`).

### מבנה תרגול (set)
`{id, kidId, name, grade(0-11), subject, topics[], examDate, dailyGoal, perRound, chapters[{title, topics[], count}], questions[], qa{checked,passed,fixed,dropped,log[]}, compete, group, created}`
שאלה: `{topic, question, options[4], answer(0-3), explanation, emoji, scene[{e,x,y,s}], ch}`
- `scene` = עד 6 אימוג'י ממוקמים (x,y 0–100, s = גודל) – "תמונה" של המצב. מוצגת עם container units (`cqh`).

## החלטות מוצר (כבר מיושמות)
**הורה – 2 לשוניות:** 👧 ילדים · 📊 פידבק
- **ילדים:** כרטיס מסך-מלא לכל ילד (החלקה), עם טבעת התקדמות, 🏆 גביעים, 🔥 ימים ברצף, שורה לכל תרגול עם ציר ימים עד המבחן, 🔗 לינק לילד, ✎ עריכה. הכרטיס האחרון = הוספת ילד (שם, כיתה, צבע).
- **אשף תרגול חדש – 4 שלבים:** למי+מקצוע+תאריך → נושאים → חומר (לא חובה) → סיכום עם ברירות מחדל ("עריכה" רק אם רוצים).
  - שאלות בכל פרק: 7–15 (בסיס לפי גיל 7/9/11/13, +2 למקצוע קליל: אנגלית, עברית, היסטוריה, תנ"ך).
  - **פרקים:** מינימום 5, עד 10, לפי כמות הנושאים. לכל פרק כמות שאלות (−/+).
  - **פרקים ביום לגביע:** מחושב מתאריך המבחן – כל החומר פעם אחת עד יום לפני, + חזרה ביום שלפני.
- **בנייה:** לא מציגים את התהליך. מסך טעינה: "⏳ התרגול יהיה מוכן בעוד כ-15 דקות", כפתור ↩ חזרה (מבטל וחוזר לסיכום) ו-🏠 (ממשיך ברקע; ⏳ בכרטיס; הודעה ✓ כשמוכן).
- **שלבי ה-AI:** סריקה → שאלות פרק-אחרי-פרק → כיסוי נושאים → **שלב תמונות חובה** → QA (פתרון עיוור, תיקון או הסרה).
- **QA תוכן:** שאלה עד 6 מילים ולא מגלה את התשובה · תשובות עד 3 מילים · הסבר עד 10 מילים · תמונה חובה · תשובה נכונה אחת. רץ אוטומטית על תרגולים ישנים כשההורה פותח (ויש כפתור 🛡️🖼️).
- **שיתוף תרגול** עם הורים אחרים (קוד SFF1), **תחרות ידידותית** אופציונלית (נקודות רק על התמדה: 10 למקצה עד 5 ביום, 5 לגביע; 0 הצלחות / מתחת ל-30% = 0 נקודות, לא מוצג), **דיווח שגיאה** עם אימות AI → מסך מנהל.
- **פידבק:** כמה תרגולים, נושאים לחיזוק (<60%, "כמעט" 60–80%) עם כפתור "סט חיזוק", נושאים שיושבים טוב (≥80%, מינימום 3 שאלות), מגמה, לקראת המבחנים.

**ילד:**
- כרטיס מסך-מלא לכל מקצוע: טבעת התקדמות + כפתור ▶ ענק, מסלול פרקים (★ / הבא / 🔁 חזרה / 🏁), גביעי היום.
- ▶ → בוחרים משחק (2×2) → בוחרים נושא או 🎲 מיקס (= הפרק הבא בתוכנית). תחנה במסלול → ישר לפרק.
- **4 משחקים:** בחירה מתשובות (מסלול עם דמות) · משחק הזיכרון (תמונה↔מילה) · התאמה בקו · חידות (הרכבת מילה מאותיות + רמז).
- **פרופיל:** הילד בוחר שם ותמונה (5 דמויות צבעוניות, 10 חיות, 📷 תמונה אישית).
- כיתות א'–ג': כפתורים גדולים + הקראה קולית אוטומטית.
